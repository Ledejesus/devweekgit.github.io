Crie vídeos completos a partir de texto.

Um estúdio estilo IA do CapCut para transformar uma ideia em roteiro, cenas animadas, legendas, narração e arquivo de vídeo — sem backend obrigatório.

Fluxo Prompt → Roteiro → Cenas → Legendas → Export A geração visual é procedural/open source. Para modelos de IA reais, conecte um backend com Stable Video Diffusion, AnimateDiff ou ModelScope.

Dica: edite qualquer cena na timeline antes de exportar. O arquivo final é gravado do canvas com a API MediaRecorder do navegador.

Este app já entrega roteiro, motion graphics, legendas, narração via Web Speech e exportação local. Para gerar imagens/vídeos com modelos abertos, adicione um backend Python com Diffusers e exponha um endpoint compatível com o adaptador descrito no README.

  • Stable Video Diffusion para image-to-video.
  • AnimateDiff para text/image-to-video com difusão.
  • ModelScope text-to-video para prototipagem.
  • FFmpeg/ffmpeg.wasm para renderização avançada.
